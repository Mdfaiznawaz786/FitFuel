# FitFuel API

Maintainer: Mohammed Faiz Nawaz

This NestJS service handles accounts, saved diets, orders, and related FitFuel API requests. See the [project README](../../README.md) for local setup and [deployment guide](../../DEPLOYMENT.md) for hosting.

## Run locally

From this directory, install dependencies and start the development server:

```powershell
npm ci
npm run start:dev
```

Configure the root `.env` file as described in the project README.
